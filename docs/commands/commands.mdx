## Moderation

| Command | Description | Usage |
| :--- | :--- | :--- |
| [`/ban`](/commands/moderation/ban) | Ban a specified user (no access) | `/ban [@user] [reason] [(time)]` |
| [`/mute`](/commands/moderation/mute) | Mute a specified user (read-only) | `/mute [@user] [reason] [(time)]` |
| [`/timeout`](/commands/moderation/timeout) | *Duplicate of the [`/mute`](/commands/moderation/mute) command* |
