# /ping

This command is used to get the latency of the bot with the server.

### Command Usage {#usage}

The ping command doesn't need any parsed value.

| command       | value    |
| ------------- | -------- |
| `/ping`       | `<none>` |

### Command Result {#result}

The bot will reply to you with the latency with the server. Mesured in milliseconds (ms).
This calculate the moment the command is sent and the reception by the server.
